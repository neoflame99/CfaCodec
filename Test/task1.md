
### make folders
```bash
rm -rf ch0_1920_1200 3840_2160_16bit
mkdir ch0_1920_1200
mkdir 3840_2160_16bit
```
위 두 폴더 아래에서 폴더를 다음 형식으로 폴더를 만든다. 

dwtlv[$0]_ngrp[$1]_sgpcd[$2]_selentp[$3]_selycc[$4]_Qp[$5]_Gb0[$6]_Gb1[$7]_Gb2[$8]_Gb3[$9]
[$n] 은 숫자로 대체로 대체한다. 
[$0]: range 1 ~ 3
[$1]: 4, 8, 16, 32
[$2]: 1 
[$3]: 0, 1
[$4]: 0 
[$5]: 8
[$6]: 0 ~ [$5] 
[$7]: 2 ~ [$5] 
[$8]: 4 ~ [$5] 
[$9]: [$5]
constraints:
1) Gb[$n] 는 Qp[$5] 의 값보다 작거나 같다.
 e.g. Gb[$6]: [$5]+1 <- 안됨.
 e.g. Gb[$6]: [$5]   <- 가능.
 e.g. Gb[$6]: [$5]-1 <- 가능.
     
2) [$7]~[$9] 는 [$n-1]보다 작을 수 없다. 
 e.g. [$6]: 3, [$7]: 0 <- 안됨.
 e.g. [$6]: 3, [$7]: 3 <- 가능.
 e.g. [$6]: 3, [$7]: 5 <- 가능.

3) [$6] ~ [$9] 은 짝수만 가진다. 
4) Gb0 ~ Gb3([$6]~[$9]가 아님)에 붙은 숫자는'[$0]'까지만 의미가 있음. 
   예를 들어 [$0]= 1 이면 Gb0[$6]과 Gb1[$7]까지만 사용된다. 따라서 
   [$0]에 따라 Gb`[$0] 이후는 [$5]로 고정한다. 

5) selentp[$3] = 0 일 때는 4 또는 8 을 가지고 selentp[$3] = 1 일 때는 16 또는 32를 가짐.

#### Notes

Qp[$5] ~ Gb3[$9]: [$5]=10, [$6]=2, [$7]=4, [$8]=[$9]=10 정도에서 visually lossless 에 가까움.
